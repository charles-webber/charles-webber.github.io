# Official Cubism R5 renderer

These browser modules are compiled from the `Framework` and TypeScript sample
included in the locally supplied Cubism SDK for Web 5-r.5 archive. They render
the bundled Hiyori model with the matching Core 6.0.1 and the official WebGL
shader sources in `shaders/`.

`LICENSE.txt` is the SDK Framework license. Model attribution is configured in
the site footer.
